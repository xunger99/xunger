Arduino PWM 信号生成与示波器测量实验

实验目的

  1. 理解脉宽调制（PWM）的周期、频率和占空比等基本概念；
  2. 掌握 Arduino PWM 输出的编程方法；
  3. 学习用示波器测量低压数字信号，并比较程序设定值与实测值。

预习材料

  1. 阅读 Arduino PWM 基础，了解 analogWrite() 的功能；
  2. 复习示波器探头、时基、触发、电压档位和占空比自动测量功能；
  3. 思考 PWM 信号为何能够用于调节 LED 平均亮度和直流电机平均功率。

实验器材

Arduino UNO 或兼容开发板1块，示波器1台及探头1支，面包板1块，LED 1个，220 Ω～330 Ω电阻1个，10 kΩ电位器1个，USB线1条，杜邦线若干，安装 Arduino IDE 的笔记本电脑1台。

实验步骤

  1. 将 LED 与限流电阻串联后接到 Arduino 的一个 PWM 引脚和GND，确认接线正确后连接 USB；
  2. 编写程序，依次执行 analogWrite() 输出值0、64、128、192和255，每种状态保持约3 s，观察 LED 亮度；
  3. 示波器探头尖端接 PWM 引脚，地夹接 Arduino GND。严禁将地夹接到其他带电节点；调整电压档位、时基和触发，使波形稳定显示；
  4. 测量每种输出值对应的高、低电平，记录周期、频率和占空比，计算理论占空比“输出值/255×100%”并比较误差；
  5. 将电位器两端接5 V和GND，滑动端接A0。把A0读数映射到0～255并实时更新 PWM，占空比应随旋钮连续变化；
  6. 使用示波器的平均值或直流测量功能记录不同占空比下的平均电压，说明平均电压与占空比的关系。

思考题

  1. analogWrite(128) 是否会输出稳定的2.5 V直流电压？为什么？
  2. PWM频率保持不变时，占空比改变会影响哪些测量量？
  3. 若要得到较平滑的直流电压，可以在PWM输出端增加什么简单电路？

考核要求

于1周内提交实验报告，内容包括程序代码、接线照片、至少5组PWM波形截图、理论与实测占空比表格、平均电压分析及思考题解答。
