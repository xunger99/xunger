单片机实验（一） 单片机基础与 Arduino 流水灯

实验目的

  1. 了解单片机的基本组成，认识数字输入、数字输出、电源和接地引脚；
  2. 掌握 Arduino IDE 的基本使用方法，完成程序编译、下载与串口调试；
  3. 学习 LED 限流电路和顺序控制方法，实现可调速度的流水灯。

预习材料

  1. 阅读 Arduino UNO Rev3 硬件介绍，了解开发板的主要引脚；
  2. 阅读 Arduino Blink 示例，了解数字输出和程序基本结构；
  3. 复习 LED 的极性、正向压降及限流电阻的计算方法。

实验器材

Arduino UNO 或兼容开发板1块，面包板1块，LED 4个，220 Ω～330 Ω电阻4个，10 kΩ电位器1个，USB线1条，杜邦线若干，万用表1个，安装 Arduino IDE 的笔记本电脑1台。

实验步骤

  1. 断电搭建电路：将4个 LED 的阳极分别经限流电阻连接至4个数字引脚，阴极接 Arduino GND。用万用表确认没有电源与地短路后再连接 USB；
  2. 打开 Arduino IDE，选择正确的开发板和串口，运行 Blink 示例，确认程序能够编译、下载且板载 LED 正常闪烁；
  3. 编写程序，将4个 LED 对应的引脚配置为输出，使 LED 按顺序依次点亮，每次只点亮1个 LED，形成流水灯效果；
  4. 修改程序，分别设置100 ms、300 ms和600 ms的切换间隔，观察并记录流水速度变化；
  5. 将电位器两端接5 V和GND，滑动端接A0。读取模拟量并将其映射为100 ms～1000 ms的延时，实现旋钮调速；
  6. 通过串口监视器输出A0读数和当前延时，检查旋钮位置、数值和流水速度是否一致。

思考题

  1. 为什么每个 LED 都必须串联限流电阻？电阻过小或过大分别会产生什么影响？
  2. 使用阻塞式延时控制流水灯时，单片机还能否及时处理其他任务？可以怎样改进？
  3. 如果要扩展到8个 LED，需要修改程序中的哪些部分？

考核要求

于1周内提交实验报告，内容包括电路连接照片、流水灯程序、三种固定速度和旋钮调速的实验现象、串口数据记录及思考题解答。
